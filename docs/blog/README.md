  분모를 NDJSON 에서 Cassandra 로 바꾸니 11.5배가 됐다. 같은 데이터, 같은 Parquet 인데 30배 차이다.

## 티스토리 작성 시 주의

- **본문 첫 줄의 `# 제목` 은 빼고 붙여넣을 것.** 제목은 에디터의 제목 칸에 따로 넣으므로
  H1 을 그대로 두면 글 안에 제목이 두 번 나온다. (리포지토리에서는 GitHub 가 문서 제목으로
  쓰기 때문에 파일에는 남겨둔다.)
- **작성 모드를 "마크다운"으로 고른 뒤에는 되돌릴 수 없다.** 글 단위로 고정되므로
  붙여넣기 전에 확인할 것
- 코드블록 언어는 `sql` / `text` 로 적었다. 티스토리 하이라이터가 `cql` 을 모르기 때문
- 표 앞뒤에는 빈 줄이 있어야 렌더링된다 (현재 본문은 지켜져 있음)
- 본문에는 리포지토리 상대 링크를 쓰지 않았다. GitHub 절대 URL 하나뿐이라
  어느 플랫폼으로 옮겨도 링크가 깨지지 않는다
